# Contributing to EnvoiSMS Open-Source Projects

Thank you for your interest in contributing to EnvoiSMS! We welcome bug fixes, documentation improvements, and SDK enhancements.

## Code of Conduct
All participants are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute
1. Fork the repository you wish to contribute to.
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Commit your changes with clear, semantic commit messages.
4. Ensure all tests and lint checks pass.
5. Submit a Pull Request describing your changes.
