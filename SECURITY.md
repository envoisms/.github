# Security Policy

EnvoiSMS.ma takes the security of our infrastructure, SDKs, and user data seriously.

## Supported Versions

| Package / Repository | Supported Versions |
| -------------------- | ------------------ |
| `envoisms` (Node)    | >= 1.0.0           |
| `envoisms` (Python)  | >= 1.0.0           |
| `envoisms-php`       | >= 1.0.0           |
| `laravel-otp`        | >= 1.0.0           |
| `@envoisms/mcp-server` | >= 1.0.0         |
| EnvoiSMS Core API    | v1                 |

## Reporting a Vulnerability

If you discover a security vulnerability within any EnvoiSMS package or the platform API, please do **NOT** open a public issue.

Instead, please report it privately:
- **Email**: security@envoisms.ma (or contact@envoisms.ma)
- **WhatsApp**: [+212 708-789095](https://wa.me/212708789095)

Please include:
1. Description of the vulnerability and its potential impact.
2. Steps to reproduce the issue (proof-of-concept script, request payload, or screenshots).
3. Any suggested remediations if available.

We commit to acknowledging your report within 24 hours and providing regular updates until resolution.
